ClinKBE: Reproducible Bayesian Computable Knowledge for BPPV and Ménière Disease

Current public research framework · v0.3.0

Open-source computable clinical-knowledge framework

  • ClinKBE is currently a vestibular-domain executable Bayesian knowledge framework covering active BPPV and Ménière disease/hydrops families.
  • Authored, reviewable clinical knowledge is transformed into versioned executable Knowledge Objects and processed by a shared Bayesian inference engine.
  • The framework separates evidence models from priors and supports exact CPD-based inference, explicit prior specification, Bayes-factor reporting, and prior-sensitivity analysis.
  • Status: evaluated with synthetic inputs as research software; patient-level calibration and external validation remain future work. It is not a validated standalone clinical diagnostic tool.

GitHub  ·  Zenodo DOI: 10.5281/zenodo.22194098

Questionnaire-Based Logistic-CPD Clinical Decision Support System for Dizziness

Clinician-facing implementation

Sole developer, software architect, and clinical implementer

  • Internal questionnaire-based clinical decision-support system used in outpatient dizziness practice at SMG-SNU Boramae Medical Center.
  • Collects structured symptom data and inferences to generate differential diagnostic rankings, independent posterior probabilities, and recommendations for next diagnostic tests.
  • Designed as a clinician-in-the-loop aid; final diagnosis, testing, and management remain under physician judgment.
  • This clinical implementation is distinct from the publicly archived ClinKBE and Vestibular-GenBN research software.

Vestibular-GenBN

Predecessor to ClinKBE

A modular generative Bayesian network framework for vestibular diagnostic knowledge engineering

  • Earlier open-source framework for modular representation of vestibular diagnostic knowledge and reproducible Bayesian inference research.
  • ClinKBE is a substantive redesign of this work, adding family-scoped mutually exclusive root states, an explicit source-to-runtime build contract, exact CPD-based inference, and separate prior/Bayes-factor reporting.
  • Preserved as part of the public development lineage rather than presented as a separate deployed clinical system.

GitHub  ·  Zenodo DOI: 10.5281/zenodo.20470541
